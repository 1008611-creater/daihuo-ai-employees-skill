# 渠道评估标准

## 10 项检查

| 项目 | 必问问题 |
|---|---|
| 官方性 | 是官方平台、官方分销，还是第三方工具？ |
| 结算 | 佣金比例、结算周期、退款扣佣规则清楚吗？ |
| 商品 | 商品链接是否能在目标平台挂车/上架？ |
| 样品 | 是否能拿样，样品和大货是否同批次？ |
| 售后 | 坏损、退货、少发、延迟谁承担？ |
| 库存 | 库存是否稳定，爆单后能否发出？ |
| 物流 | 发货地、时效、不可达地区是否清楚？ |
| 资质 | 食品、美妆、滋补、母婴等资质是否齐？ |
| 内容素材 | 是否有实拍、卖点、证明、用户反馈？ |
| 风险 | 是否有违规词、夸大功效、虚假宣传风险？ |

## 渠道建议

- 新手达人：优先官方分销平台和低售后风险商品。
- 有内容能力但无供应链：官方分销 + 第三方数据工具找机会。
- 有货源商家：先做平台自播和商品内功，再进分销找达人。
- 做生鲜：优先自控供应链或明确售后的供货渠道，不盲目追高佣。
- 做小红书：优先可真实体验、能拍细节、适合搜索种草的商品。

## 红线

- 只看佣金不看退货。
- 只看销量不看评价和差评原因。
- 第三方工具里看到爆品就直接拍，不回官方平台核验。
- 不拿样就讲体验。
- 供应商不能给售后规则还安排直播主推。
