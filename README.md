# 带货 AI 员工 Codex Skill

这是一个给 Codex App 使用的本地 Skill，用来把 Codex 变成电商带货运营中控。

适合场景：

- 抖音、快手、小红书短视频带货
- 直播带货脚本和节奏设计
- 商品选品分析
- 评论区和私信回复
- 每日带货数据复盘

## 能做什么

安装后，你可以直接在 Codex 里说：

```text
请使用带货 AI 员工，为下面商品生成今天可执行的带货运营包。
```

它会按这几个岗位输出：

- 选品研究员
- 短视频编导
- 直播运营
- 评论客服
- 复盘分析员

## 安装

查看 [INSTALL.md](INSTALL.md)。

最简单的方式是把 `daihuo-ai-employees` 文件夹复制到：

```text
C:\Users\<你的用户名>\.codex\skills\daihuo-ai-employees
```

macOS/Linux:

```text
~/.codex/skills/daihuo-ai-employees
```

然后重启 Codex App。

## 说明

这个 Skill 不负责自动登录平台、自动发布视频或自动回复用户。它负责生成可执行的运营内容、脚本、话术和复盘建议。
