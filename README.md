# 带货 AI 员工 Skill Pack

这是一个给 Codex App 使用的本地带货员工团队，不是单个提示词。它把电商带货拆成多个岗位：先用数据选品，再判断从哪里上货，接着确定平台打法，最后生成内容并做复盘。

适合场景：

- 抖音、快手、小红书短视频带货
- 直播带货脚本和节奏设计
- 商品选品、测品、爆品判断
- 巨量百应、快分销、小红书蒲公英、猿推推等上货/分销渠道判断
- 评论区、私信、售后异议回复
- 每日带货数据复盘和下一轮优化

## Skill 列表

安装后建议完整保留这 6 个文件夹：

- `daihuo-ai-employees`：总控员工，负责把完整任务拆成选品、货源、平台、内容、复盘。
- `daihuo-product-selection`：选品数据员工，负责数据依据、商品评分、利润/佣金、退货风险和是否值得测。
- `daihuo-supply-channels`：货源渠道员工，负责判断从巨量百应、快分销、蒲公英、猿推推、自有供应链等哪里上货。
- `daihuo-platform-playbooks`：平台路径员工，负责抖音、快手、小红书的带货入口、打法差异和适配判断。
- `daihuo-content-conversion`：内容转化员工，负责短视频脚本、直播话术、评论回复和合规表达。
- `daihuo-growth-review`：复盘增长员工，负责看播放、点击、成交、退货、评论数据，决定继续、换角度、换货源或暂停。

## 安装

查看 [INSTALL.md](INSTALL.md)。

最简单的方式是把本仓库里的所有 `daihuo-*` 文件夹复制到：

```text
C:\Users\<你的用户名>\.codex\skills\
```

macOS/Linux:

```text
~/.codex/skills/
```

然后重启 Codex App。

## 依据来源

这套 skill pack 沉淀了官方平台路径和常用数据工具的工作方法。实际使用时，优先把你自己的后台数据、平台数据和商品证据填进去；没有数据时，skill 会输出补数任务，而不是假装有结论。

## 说明

这个 Skill Pack 不负责自动登录平台、自动发布视频或自动回复用户。它负责让 Codex 生成可执行的选品判断、渠道判断、平台路径、脚本话术和复盘建议。
