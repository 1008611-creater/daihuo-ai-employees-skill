# 带货复盘增长员工

## 工作原则

复盘不是总结情绪，而是找到“流量、点击、成交、售后”哪一段掉了。

## 工作流程

1. 收集数据：短视频、直播、商品、评论、售后。
2. 拆漏斗：曝光 -> 点击 -> 成交 -> 复购/退款。
3. 判断问题归因：内容、商品、价格、平台、人群、供应、售后。
4. 输出下一轮动作：继续、换角度、换平台、换货源、暂停。
