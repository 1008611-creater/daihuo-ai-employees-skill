# 账号/视频侦察

定位：选品第一步不是找商品，而是先找到足够优质、有爆点、好模仿、有商业价值的账号或视频样本。

## 目标

先建立候选样本池，再进入爆款拆解。

优先找：

- 低粉高爆账号：粉丝不高，但单条视频互动明显高于账号均值。
- 连续爆账号：同一账号近期多条内容数据好，说明内容模型稳定。
- 商品强相关视频：评论区出现链接、价格、尺码、同款、哪里买、效果、售后等购买意图。
- 可模仿账号：画面、动作、脚本、场景、人物门槛低，团队可以复刻。
- 商业价值明确账号：挂车、直播、达人合作、商品橱窗、店铺、品牌合作痕迹清楚。

## 开源/工具调研结论

| 工具 | 适合用途 | 适合程度 | 注意 |
|---|---|---:|---|
| MediaCrawler | 多平台关键词搜索、指定创作者主页、帖子/视频信息、评论、二级评论、数据导出 | 5/5 | 最适合作为本地候选样本采集底座；项目声明仅供学习研究，商业使用要谨慎 |
| TikHub API / SDK | 抖音、小红书、快手等平台的视频、用户、评论、搜索、趋势、电商数据 API | 4/5 | 更稳定但偏付费 API，不算纯开源采集器 |
| Just One API | 抖音/小红书/快手用户搜索、视频搜索、评论、电商/星图/蒲公英等接口 | 4/5 | 适合快速工程化，但依赖外部 API 服务 |
| XHS-Downloader | 小红书搜索结果作品链接、用户链接、账号作品、作品信息采集 | 3/5 | 小红书专项好用，但不是多平台方案 |

## 推荐方案

先用 MediaCrawler 做本地样本采集底座；如果要稳定、批量、少折腾，再接 TikHub 或 Just One API。

第一阶段不要追求全自动选品，先做半自动：

1. 输入类目关键词，例如女童连衣裙、男装通勤、微胖女装、亲子穿搭。
2. 采集抖音/快手/小红书搜索结果和创作者主页。
3. 拉取视频/笔记标题、正文、发布时间、点赞、评论、收藏、转发、作者粉丝、评论内容。
4. 计算初筛指标：互动率、低粉爆发度、评论购买意图、复刻难度、商品清晰度。
5. 输出 Top 20 账号/视频样本。
6. 再进入爆款视频账号拆解。

## 初筛评分

| 维度 | 分值 | 判断 |
|---|---:|---|
| 低粉高爆 | 20 | 粉丝低但互动高，排除纯头部账号势能 |
| 评论购买意图 | 25 | 链接、价格、尺码、同款、哪里买、效果、售后等词密度 |
| 商品/品类清晰 | 15 | 能明确反推类目、价格带、使用场景 |
| 复刻难度低 | 15 | 不依赖明星、强剧情、重拍摄团队、特殊场地 |
| 差异化/反差明显 | 15 | 前 3 秒有视觉差、身份差、场景差、效果差 |
| 商业链路清楚 | 10 | 挂车、橱窗、店铺、直播、合作痕迹清楚 |

70 分以上进入人工拆解；低于 70 分只作为内容灵感。

## 购买意图关键词

服装类优先看：

- 链接、同款、哪里买、怎么买、求店铺、购物车。
- 价格、多少钱、贵不贵、活动、优惠。
- 尺码、身高体重、偏大偏小、版型、显瘦、遮肉。
- 面料、起球、掉色、透不透、厚薄。
- 退换、运费险、发货、质量、色差。

童装额外看：

- 身高、体重、年龄、尺码、上学、演出、六一、生日。
- 质量、安全、面料、舒服、掉不掉色、扎不扎。
