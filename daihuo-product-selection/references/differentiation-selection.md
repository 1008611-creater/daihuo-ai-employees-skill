# 差异化/反差选品

差异化和反差必须前置到选品层。短视频带货不是先找普通商品再硬写脚本，而是先找有“可感知不同”的商品机会。

## 核心原则

- 反差不是猎奇，必须服务成交。
- 反差必须能被画面、试穿、测试、对比、评价或数据证明。
- 只有文案能讲出差异，画面和商品本身看不出来，反差分要降低。
- 同质化商品如果没有价格、场景、人群、功能、信任或内容表达差异，不作为短视频主推。

## 反差类型

| 类型 | 说明 | 例子 |
|---|---|---|
| 效果反差 | 使用前后变化明显 | 清洁前后、收纳前后、旧物翻新、衣服上身前后 |
| 人群反差 | 商品和人群之间有新鲜关系 | 男装女穿、微胖显瘦、中年男士穿出精神感、妈妈装年轻化 |
| 场景反差 | 商品突破原有使用场景 | 家居服外穿、通勤西装日常化、户外防晒单品通勤用 |
| 价格反差 | 观感或体验超出价格预期 | 看着贵但价格友好、基础款但面料扎实 |
| 痛点反差 | 解决同类商品常见槽点 | 女装尺码真实、裤子不勒肚子、T 恤不透不变形 |
| 信任反差 | 信任来源不同于普通卖货 | 源头工厂、真人长期实测、洗后对比、差评反向验证 |
| 情绪反差 | 用户有强烈共鸣或吐槽 | “终于不是纸片人尺码”“给老公买衣服不用猜码” |

## 反差评分

| 维度 | 分值 | 判断标准 |
|---|---:|---|
| 第一眼感知 | 25 | 3 秒内是否能看出不同 |
| 购买相关性 | 25 | 反差是否直接变成购买理由 |
| 可证明性 | 20 | 是否能通过画面、试穿、测试、评价证明 |
| 可复刻性 | 15 | 我们能否用自己的账号、场景和样品复刻 |
| 风险可控 | 15 | 是否避免虚假宣传、夸大效果和售后风险 |

结论：

- 80-100：强反差，可作为主爆点。
- 60-79：有差异，但需要补画面或证据。
- 40-59：弱差异，只适合直播讲解或货架补充。
- 40 以下：同质化，不建议短视频主推。

## 服装反差重点

女装：

- 不只看好看，要看“和用户踩过的坑形成反差”。
- 优先找：尺码真实、微胖友好、上身显精神、不透、不勒、不预售、洗后不变形。
- 危险反差：过度显瘦、过度修身、滤镜强、只靠模特身材。

男装：

- 重点找“普通男性穿上也有变化”的反差。
- 优先找：肚子不明显、肩背更精神、面料不廉价、洗后不皱、老婆/家人决策友好。
- 危险反差：夸大科技面料、过度承诺凉感/防晒/不起球。

童装：

- 重点找“家长安全感”和“孩子穿着舒服”的反差。
- 优先找：无异味、标签不扎、好穿脱、耐洗、活动不勒、校园场景明确。
- 危险反差：只靠可爱外观，无安全类别、吊牌和执行标准支撑。
