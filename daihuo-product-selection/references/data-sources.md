# 数据来源清单

## 官方数据

- 抖音：巨量百应、精选联盟、抖音电商罗盘、抖店后台。
- 快手：快分销、快手小店、快手电商学习基地、选品中心。
- 小红书：蒲公英平台、专业号平台、商家/店铺后台、合作中心。

优先使用官方数据，因为它最接近真实成交和平台规则。

## 爆款样本

选品前必须先收集爆款短视频、爆款账号或爆款直播间样本。样本用于判断需求和内容爆点是否已经被验证。

优先级：

- 低粉账号高播放、高互动的视频。
- 近期 7-30 天还在增长的视频。
- 评论区有明确购买意图或反复追问价格、链接、效果、售后的视频。
- 多个账号反复卖同类商品或同类需求的视频。
- 挂车商品重复出现，并且评价、销量、达人带货记录可核验的视频。

样本不足时，不建议商品直接入池。

## 第三方数据工具

- 抖音/直播电商：蝉妈妈、飞瓜、考古加、新抖、抖查查、灰豚等。
- 快手：飞瓜快数、新快、快手相关第三方直播电商数据工具。
- 小红书：千瓜、新红、灰豚、艺恩等。

第三方数据用于发现趋势、竞品、达人、内容模板，但要注意口径和估算误差。

## 人工观察

- 平台搜索下拉词、热搜词、评论区高频问题。
- 竞品短视频的点赞、评论、收藏、挂车、评论购买意向。
- 直播间蹲点：在线、互动、讲解节奏、商品点击、用户问题。
- 样品体验：开箱、质量、卖点是否真实、是否好拍。
