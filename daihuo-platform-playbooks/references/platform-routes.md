# 平台路径

## 抖音

适合：

- 强画面、强钩子、能短时间解释清楚价值的商品。
- 可通过短视频、直播、商品卡、搜索承接的商品。

常见路径：

- 达人：开通商品分享权限 -> 巨量百应/精选联盟选品 -> 橱窗/短视频/直播挂车。
- 商家：抖店上架 -> 商品内功优化 -> 自播/短视频/精选联盟找达人 -> 用罗盘复盘。
- 品牌/供应链：抖店/供销/精选联盟 -> 招商团长/达人机构 -> 达播与店铺承接。

关键数据：

- 商品曝光、点击、点击率、成交转化、GMV、退款、好评率。
- 短视频完播率、商品曝光、商品成交金额、千次曝光成交金额。
- 直播商品点击、点击成交转化、商品成交件数、退款和差评。

## 快手

适合：

- 需要信任、人设、复购、直播反复讲解的商品。
- 食品、日用、服饰、美妆个护、品牌好货、源头好货。

常见路径：

- 达人：快手小店/卖家端 -> 快分销选品中心 -> 开通推广权限 -> 带货赚佣金。
- 商家：快手小店开店 -> 开通快分销供货 -> 设置推广计划 -> 找达人/团长。
- 品牌：快分销 + 自播 + 达播矩阵。

关键数据：

- 选品中心热度、佣金、商品口碑、直播成交、粉丝互动、复购反馈。
- 老客信任、主播与粉丝匹配度比短期爆发更重要。

## 小红书

适合：

- 能真实体验、能拍细节、适合搜索和收藏的商品。
- 美妆、穿搭、母婴、食品、家居、旅行、生活方式、礼物类。

常见路径：

- 品牌/商家：专业号/店铺 -> 蒲公英平台 -> 找博主/买手做内容或直播合作。
- 创作者：合作中心/商品合作/直播合作 -> 选品 -> 笔记或直播种草。
- 店铺商家：绑定店铺 -> 用内容承接搜索和店铺成交。

关键数据：

- 阅读、点赞、收藏、评论、搜索词、互动率、种收指数、GMV、收藏后转化。
- 小红书先看“用户是否愿意收藏和搜索”，再看成交。
