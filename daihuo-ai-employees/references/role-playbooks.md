# 岗位打法

## 选品研究员

输出重点：

- 商品是否值得今天推，评分 1-10 分。
- 适合平台：抖音、快手、小红书、直播间、私域。
- 主卖人群：谁最容易买，为什么现在买。
- 成交阻力：价格、信任、物流、售后、同质化、季节性。
- 证明材料：产地、实拍、切开、称重、对比、检测、评价、售后规则。

判断口径：

- 低客单标品：靠钩子、场景、价格锚点。
- 生鲜水果：靠新鲜度、批次展示、真实切果、售后信任。
- 高佣产品：先确认是否好解释、好展示、好证明。
- 小红书：优先“真实体验 + 搜索词 + 场景”。
- 快手：优先“人设可信 + 源头可信 + 老客复购”。
- 抖音：优先“前三秒冲突 + 强画面 + 立即购买理由”。

## 短视频编导

每条脚本必须包含：

- 标题：不超过 24 字，避免极限词。
- 前三秒钩子：一句话抓住痛点或好奇。
- 画面分镜：至少 4 个镜头。
- 口播：主播能直接读。
- 商品植入：自然说明规格、价格、卖点、售后。
- 评论引导：引导问规格、口味、发货、适合人群。

常用结构：

- 痛点开场：你是不是也遇到过 X。
- 对比开场：同样是 X，为什么这一批更适合 Y。
- 场景开场：办公室/孩子放学/晚饭后/送礼。
- 证据开场：现场切开、称重、试吃、包装、发货。

## 直播运营

60 分钟基础节奏：

- 0-5 分钟：建立信任，讲今天主推、福利、售后规则。
- 5-15 分钟：第一次完整讲品，展示核心卖点和实物证据。
- 15-30 分钟：互动答疑，处理价格、质量、发货、售后异议。
- 30-45 分钟：第二轮强成交，强调适合人群、库存、套餐。
- 45-55 分钟：复述权益，拉新进来的用户重新理解商品。
- 55-60 分钟：下播收口，提醒未付款、售后、明天预告。

讲品公式：

痛点 -> 展示 -> 证明 -> 适合谁 -> 不适合谁 -> 套餐/价格 -> 售后 -> 行动提醒。

## 评论客服

回复原则：

- 先回答问题，再补一句信任或场景。
- 不硬怼质疑，先承认顾虑合理。
- 不承诺过度售后，按平台和店铺规则说。
- 评论区回复短，私信回复可更详细。

常见类型：

- 问价格：说明套餐、规格、是否含运费。
- 问质量：强调批次、实拍、发货前检查。
- 问发货：说明时效以订单和物流为准。
- 质疑太贵：讲规格、产地、筛选、售后，不说全网最低。
- 问适合谁：按人群和场景回答。

## 复盘分析员

短视频看：

- 3 秒留存、完播率、互动率、商品点击率、成交转化。

直播看：

- 进入人数、停留、互动、商品点击、加购、成交、退款/售后。

评论看：

- 高频问题、质疑点、未解释清楚的卖点、用户真实用词。

决策：

- 播放高点击低：卖点不清或商品承接弱。
- 点击高成交低：价格、信任、售后或详情页有问题。
- 评论多质疑多：下一条视频优先做证据和答疑。
- 数据全低：换钩子、换人群、换平台或暂停测品。
