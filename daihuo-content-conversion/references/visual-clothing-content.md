# 视觉种草/舞蹈穿搭内容模板

适用于女装、小裙子、童装、亲子装等以动态视觉效果带动咨询和转化的内容。

## 成人女装舞蹈穿搭

前提：

- 模特为成年人，商用授权清楚。
- 舞蹈动作健康自然，不低俗，不靠身体凝视吸流量。
- 衣服是主角，商品细节镜头必须足够。

脚本：

```text
标题：
平台：
商品：
目标人群：
反差点：静态普通 / 上身惊艳 / 转身有裙摆 / 显精神

镜头 1（0-3 秒）：静态上身或换装前后反差，直接给最好看的动态画面。
镜头 2（3-6 秒）：走两步或轻舞，展示版型、裙摆、腰线。
镜头 3（6-10 秒）：面料、拉链、袖口、内衬、厚薄特写。
镜头 4（10-15 秒）：不同光线或不同距离下整体效果。
镜头 5（15-20 秒）：尺码/身高体重参考，提醒看详情或评论问同款。

字幕：
口播：
商品植入：
评论引导：
风险提醒：
```

## 童装/萌娃才艺场景

前提：

- 监护人授权，平台规则允许。
- 儿童不口播卖货，不喊购买，不劝家长下单。
- 不展示学校、住址、姓名等隐私。
- 不做儿童内衣、泳衣、贴身敏感品类真人展示。
- 商品必须有吊牌、执行标准、安全类别和售后说明。

脚本：

```text
标题：
平台：
商品：
适合场景：生日 / 六一 / 校园演出 / 春游 / 日常拍照
核心卖点：好看 / 好穿脱 / 活动方便 / 不扎 / 耐洗

镜头 1（0-3 秒）：儿童开心转圈或才艺片段，但不口播卖货。
镜头 2（3-6 秒）：成人旁白或字幕说明场景，例如“六一演出小裙子，重点看活动方不方便”。
镜头 3（6-10 秒）：衣服近景，展示面料、内衬、肩带/袖口、装饰件。
镜头 4（10-15 秒）：活动场景，展示跑跳、转身、坐下是否方便。
镜头 5（15-20 秒）：成人手持吊牌或尺码说明，给家长选择参考。

字幕：
成人旁白：
商品植入：
评论引导：
风险提醒：
```

## 禁止写法

- “小朋友快让爸爸妈妈买。”
- “不买孩子会难过。”
- “全网最美小公主裙。”
- “穿上秒变校花/女神。”
- “孩子自己推荐，真的超爱。”

## 推荐写法

- “适合六一/生日/演出这类需要出片的场景。”
- “重点看活动方不方便，坐下会不会勒。”
- “家长选童装先看吊牌、安全类别和面料。”
- “尺码按身高体重选，拿不准先问客服。”

## 规则依据

- 抖音电商对“利用未成年人营销”有实施细则，禁止不当利用未成年人进行商品营销、让未成年人介绍商品卖点或劝诱购买。
- 快手小店带货达人宣传规范要求不满十六周岁的未成年人不得推广商品、参与营销，并要求宣传真实、专业、准确。
- 商业使用真人或童模肖像前必须取得明确授权，素材来自网络不能作为免责理由。
