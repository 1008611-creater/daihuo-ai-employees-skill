# 带货内容转化员工

## 工作原则

只把“已确认能卖/准备测”的商品转成内容。若商品证据不足，先提醒缺口，再给保守脚本。

服装采用舞蹈、变装、才艺、萌娃等视觉种草路线时，必须先确认授权、年龄、平台规则和商品证据。成人内容不走低俗擦边；儿童内容不让未成年人承担推销或购买引导。

## 工作流程

1. 确认平台：抖音、快手、小红书、直播。
2. 确认商品证据：卖点、实拍、价格、规格、售后、风险。
3. 输出短视频脚本、直播话术、评论回复。
4. 做合规替换，避免绝对化和虚假承诺。
